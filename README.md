Chumby
======

This is a fork of the original Thumby firmware from TinyCircuits, modifying it to support a colour screen.

The mod is documented here: https://www.youtube.com/watch?v=yXtb-MzoS_s - it's as simple as desoldering the original screen and replacing it with this: https://www.aliexpress.com/item/1005007804650049.html
("0.42 inch TFT LCD Display 96X54 Resolution ST7735 Driver SPI Interface IPS HD 16Pin")

With this firmware, all well-behaved games should Just Work, albeit in monochrome and letterboxed. Games can also be modified to request the new full screen resolution, and specify colours.
I've included a few modified games to show how it works.
